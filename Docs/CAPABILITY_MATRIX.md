# MacWatch capability matrix

This matrix describes the implemented version, not an aspirational security product. “Active” means MacWatch is running; it does not mean the Mac is safe.

| Area | What MacWatch actually observes | Mode | Permission | Limits and blind spots |
|---|---|---|---|---|
| Camera | CoreMediaIO device connection and `kCMIODevicePropertyDeviceIsRunningSomewhere` state | Live-ish, public API polled every 2 seconds | None requested; MacWatch never opens a capture stream | Short activity between polls can be missed. Process attribution is unavailable and shown as Unknown. Device activity is not proof of malicious use. |
| Microphone | CoreAudio input-device presence and `kAudioDevicePropertyDeviceIsRunningSomewhere` state | Live-ish, public API polled every 2 seconds | None requested; MacWatch never opens an audio stream | Short activity can be missed. Combined input/output and virtual devices can cause imperfect attribution. Responsible process is unavailable. |
| User LaunchAgents | Additions, removals, and content modifications to readable `~/Library/LaunchAgents/*.plist`; `Program`/first `ProgramArguments` value and static signature metadata when available | Periodic, every 10 seconds | Ordinary file access | Only this explicitly named directory and `.plist` files. Initial inventory is a baseline. Atomic changes between scans can be missed. Signature metadata is not a safety verdict. |
| Remote Login / SSH configuration | Remote Login enablement, SSH allowed-user group membership, fingerprints of readable `sshd_config` files, and the current user's `~/.ssh/authorized_keys` | Periodic, every 15 seconds | Ordinary read access; no administrator prompt | This observes configuration changes, not login attempts or active sessions. `launchctl` and directory-service output are system interfaces whose presentation may change. Key contents are never stored. Initial inventory is a baseline. |
| SSH authentication | Not active in the current build | Unavailable | Apple's restricted Endpoint Security entitlement | Implementation source is retained but the extension is not embedded, activated, or polled. SSH configuration and active SSH sessions remain covered separately. |
| Active SSH sessions | Remote terminal sessions reported by the macOS login-session table, including account, source, start time, disappearance, and derived duration | Periodic, every 15 seconds | Ordinary session-table access | SSH commands and port-forwarding sessions created without a terminal may not appear. The current build has no authentication-event fallback. Abrupt shutdown can prevent a closure event. Hostnames and NAT can make source identity unstable. |
| Listening endpoints | TCP sockets in `LISTEN` state and unconnected bound UDP sockets, with address family, local address/port, exposure classification, process name/PID, and executable path when visible | Periodic, every 15 seconds; persisted baseline | Ordinary access to macOS socket/process inventory | SigNoz receives transport, local bind address, port, exposure, and process name for opened/closed events. PID and executable path remain local. A listener is not proof of firewall/router reachability or malicious activity. Short-lived sockets between scans can be missed. UDP has no listening state and can be noisy. |
| Sleep/wake | Workspace sleep and wake notifications and the observed gap | Live notification while app runs | None | App termination/crash cannot be recorded locally after it occurs. Sleep pauses polling and heartbeats. |
| Local notifications | Selected activation/startup events, deduplicated for five minutes | Live after an event | User notification permission, requested only from the UI | Muting, Focus, or system settings can suppress presentation. |
| Screen capture | Privacy-review guidance only | Manual | None | Automatic screenshot/screen-recording detection is unavailable. There is no claim of universal coverage. |
| Other apps’ privacy grants | Links and manual navigation guidance | Manual | None | MacWatch does not read the protected TCC database and cannot enumerate other apps’ grants. |
| Remote access | Sharing-settings review guidance | Manual | None | A configured service, running app, and verified active session are distinct. MacWatch does not claim active-session detection. |
| Established per-process connections | Not implemented | Unavailable | None | Listening endpoints are covered separately. Ordinary public APIs without Network Extension/Endpoint Security do not provide the requested reliable continuous attribution. Encrypted traffic would not reveal transferred content. |
| SigNoz | Sanitized allowlisted logs and health metrics sent directly with OTLP/HTTP JSON | Optional periodic batches; heartbeat every 60 seconds while awake | Explicit enablement; ingestion key in Keychain; network access | Network loss, sleep, shutdown, app exit, authentication failure, rate limiting, or interference can create gaps. A delayed heartbeat older than 120 seconds is discarded. |

## Supporting public documentation

- Apple documents [`kCMIODevicePropertyDeviceIsRunningSomewhere`](https://developer.apple.com/documentation/coremediaio/kcmiodevicepropertydeviceisrunningsomewhere) and [`kAudioDevicePropertyDeviceIsRunningSomewhere`](https://developer.apple.com/documentation/coreaudio/kaudiodevicepropertydeviceisrunningsomewhere) as public device-running state properties.
- Apple documents [`NSWorkspace.didWakeNotification`](https://developer.apple.com/documentation/appkit/nsworkspace/didwakenotification) and the corresponding `willSleepNotification` on `NSWorkspace`.
- Apple documents [`SecCodeCopySigningInformation`](https://developer.apple.com/documentation/security/seccodecopysigninginformation(_:_:_:)) for on-disk signature information.
- Apple documents the Endpoint Security [`es_event_openssh_login_t`](https://developer.apple.com/documentation/endpointsecurity/es_event_openssh_login_t) event with success, result type, source address, and username fields.
- Apple requires contextual authorization before scheduling local notifications: [`requestAuthorization(options:)`](https://developer.apple.com/documentation/usernotifications/unusernotificationcenter/requestauthorization(options:)).
- The [OTLP specification](https://opentelemetry.io/docs/specs/otlp/) defines JSON-over-HTTP paths, response behavior, retryable status codes, throttling, and partial success.
- SigNoz documents the [current Cloud endpoints and ingestion-key header](https://signoz.io/docs/ingestion/signoz-cloud/overview/) and [OTLP environment/encoding options](https://signoz.io/docs/ingestion/opentelemetry-environment-variables/).

No public Apple API was found that, within the stated ordinary-user/no-restricted-entitlement constraints, provides universal screen-capture detection, other-app TCC grant enumeration, reliable active remote-session proof, or per-process connections. Unsupported rows are therefore explicit rather than inferred from process names or open ports.
